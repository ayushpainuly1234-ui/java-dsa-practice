# Java DSA Practice

A collection of standalone Java programs used to practise programming fundamentals and problem-solving.

## Topics covered

- **Java fundamentals:** input/output, variables, methods, arguments, conditionals and loops.
- **Math and number problems:** divisibility, prime/composite checks, factorial, powers and number operations.
- **Pattern printing:** triangles, pyramids, diamonds, squares and other console patterns.
- **Arrays:** searching, reversing, maximum elements and array transformations.
- **2D arrays / matrices:** input, traversal, transpose, spiral and wave-style printing.

The source files are independent practice exercises rather than one application. Open and run one program at a time; some older exercises use filenames that differ from the class name declared inside the file.

## Run a program

1. Install a JDK (Java 17 or newer is a reasonable default).
2. Open one Java source file and check the class name declared in it.
3. Compile and run that specific class from the terminal. Do not compile this entire collection as one application.
